# Future work

Not implemented in the hackathon build:

- **Map of all locations** with their trends (the app currently shows a single pin for the selected point).
- **Upload of a user's own NASA POWER file** as an offline fallback when the API is unreachable.
- **More variables**, each with its own correct aggregation (precipitation needs totals, not means).
- **Trend robustness**: autocorrelation-adjusted uncertainty (for example a pre-whitened Mann–Kendall test) and start-year sensitivity.
- **Explanations in Spanish, French and Haitian Creole**, and optional AI-written explanations.
- **Seasonal or monthly trends** in addition to annual means.
- **More than two locations** at once.
- **Regional and global benchmarks** built from area averages, so that questions like "is the Caribbean warming faster than the world?" can be answered properly.
- **Guided walkthrough** for first-time users.
- **Recorded demo.**
